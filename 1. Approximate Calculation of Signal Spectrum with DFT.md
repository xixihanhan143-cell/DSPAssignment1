## [Background Knowledge]

Sounds include speech sounds, musical sounds, noise, etc. A musical note is a sound with a fixed pitch produced by the regular vibration of a sound-producing object, such as 1(Do), 2(Re), 3(Mi) in music. A string of musical notes arranged in pitch order is a scale, such as the familiar $\mathrm { 1 ( D o ) 2 ( R e ) 3 ( M i ) 4 ( F a ) 5 ( S o ) 6 ( L a ) 7 ( S i ) }$ . A musical note is made up of sinusoidal signals of different frequencies, and its simplest mathematical model is cos(2ft), as shown in the table below for the frequencies of the notes on the C major scale:

4. The spectral components of chords. A chord is generally composed of three (or more than three) regular musical notes, that is $x ( t ) { = } \cos ( 2 \pi f _ { 1 } t ) { + } \cos ( 2 \pi f _ { 2 } t ) { + } \cos ( 2 \pi f _ { 3 } t )$
